## Known Issues / Findings in `src` (Reported Only or Isolated)
- `src/sim/waveSystem.ts`: In Endless Mode, `canStartNextWave()` returns `true` during `allSpawned`, so repeatedly calling the next wave early before active enemies clear stacks multiple 100+ enemy waves simultaneously and can saturate `BALANCE.pools.maxEnemies` (360) — observed `enemyPool.acquire()` returning `null` (16 dropped spawns on L7 when stacking waves 19–27 without clearing). `SimWorld` handles `null` without crashing.
- `src/sim/enemySystem.ts`: When a `splitter` dies at exact pool capacity (360/360), `spawnSplitChild` runs before `pool.releaseAtActivePos(pos)`, so both hatchlings fail to acquire slots even though the parent is releasing 1 slot on that step.
- `src/render/geometryHelpers.ts`: `mergeColoredParts([])`, `mergePlainGeometries([])`, and `mergeTexturedParts([])` call Three.js `mergeGeometries(prepared, false) ?? new THREE.BufferGeometry()`, but Three.js 0.187 `mergeGeometries` throws `TypeError: Cannot read properties of undefined (reading 'index')` when given an empty array (missing `if (prepared.length === 0) return new THREE.BufferGeometry();` guard). All current callers pass non-empty arrays.
- `src/data/levels/index.ts`: Does not re-export `ScriptedBuildAction`, though `scripts/balanceSim.ts` imports it from there (ignored at runtime by `tsx`, flagged only if strict `tsc` checks `scripts/`).
- `src/platform/storage.ts`: `loadProgress` checks `typeof parsed.unlockedLevelIndex === 'number'` without `Number.isFinite(...)` (unlike `bestStars`/`bestEndlessWaves`).
- `src/platform/input.ts` (`lines 158–173, 302`): `window.addEventListener('pointercancel', onPointerUp)` routes browser `pointercancel` events through `onPointerUp`, causing a cancelled single-pointer touch (`pointers.size === 1 && !this.isDragging`) to emit a phantom `onPrimaryTapNdc` / `onSecondaryAction('rightClick')` instead of just clearing the pointer (`if (e.type !== 'pointercancel')`). Left untouched in `src/` to avoid merge conflicts with the parallel mobile UI / radial touch menus branch.
- `src/platform/gameSession.ts` (`lines 229–234`): If a player clicks "Continue Endless" (`ws.isEndless = true`, `ws.currentWaveOneBased === level.waves.length`) and quits or restarts before Wave `N+1` starts, `recordEndlessIfActive()` persists `bestEndlessWaves[levelIndex] = level.waves.length` even though 0 endless waves were reached.
- `src/sim/enemySystem.ts` (`lines 230–241`) & `src/sim/world.ts` (`lines 355–365`): `onLeak(e)` executes before `this.events.emit('enemyLeaked', ...)`, so a fatal leak emits `gameLost` before its own `enemyLeaked`, and any extra same-tick leakers emit `economyChanged` + `enemyLeaked` after `gameLost` (`gameLost` still fires once and `lives` remains clamped at `0`).
- `src/ui/tooltip.ts` (`lines 43, 63`): `Math.min(window.innerWidth - 190, clientX + offsetX)` (and `- 260` in `showTower`) lacks a lower-bound `Math.max(..., ...)` clamp, allowing negative `left` coordinates on narrow viewports (`< 260px`) or negative offsets (left untouched in `src/ui/**`).
- `src/sim/waveSystem.ts` (`lines 331–342`): `skipToWave(waveOneBased)` computes `Math.max(0, Math.floor(waveOneBased) - 1)` without a `Number.isFinite` guard (`NaN` yields `clampedIdx = NaN`; `Infinity` in endless yields `clampedIdx = Infinity`), causing `startNextWave` to advance with a non-finite `currentWaveIndex`.
- `src/platform/gameSession.ts` (`lines 219–225`): `syncFlightPathHighlight()` checks `ws.state === 'spawning' || ws.state === 'clearing'`, omitting `ws.state === 'allSpawned'`, so on an island's final story wave (`nextPreview === null`) the aerial flight-path highlight turns off as soon as the final wave finishes spawning while flyers may still be airborne.
- `src/ui/buildBar.ts` (`lines 38–44`) & `src/ui/abilityBar.ts` (`lines 213–216`): `shortNames: Record<TowerType, string>` hardcodes the 5 base tower keys and `shortLabels: Record<AbilityId, string>` hardcodes the 2 ability keys (reminder for TOWERS merges alongside `TOWER_ICON_SVGS` in `src/ui/icons.ts`).
- `src/ui/towerPanel.ts` (`lines 288–294`): `TowerPanel.update` uses an `if (stats.splashRadius > 0) ... else if (stats.slowRatio > 0)` chain, so Frost Spire (`splashRadius: 1.65`, `slowRatio: 0.28`) renders `1.7m AoE` and omits the `Slow` stat chip even though its upgrade diffs show `+7%` slow (left untouched in `src/ui/**`).
- Render triangle baseline (real Kenney GLBs on L9 `grand-skyhold`, 40 towers T1–T3, 250 enemies, 48 projectiles): measured `239,055` visible triangles (`> 2,500` combined tris on heaviest single Kenney tower base+turret pair), useful reference for PERF / mobile triangle tuning.
- `src/render/towerBadges.ts` (`lines 223–229`): `TowerBadgeRenderer.dispose()` disposes `this.geometries`, `this.material`, and `this.atlas`, but omits `disposeInstancedMeshes` / `.dispose()` on `this.tierMeshes` & `this.arrowMesh` and omits `this.group.clear()` (contrast other renderers; left untouched for PERF/render ownership).
- `src/core/eventBus.ts` (`lines 137–151`): `EventBus.emit` iterates `for (let i = 0; i < list.length; i++)` over the live listener array while the unsubscribe closure calls `list.splice(idx, 1)`, so if listener `i` unsubscribes itself mid-`emit`, listener `i + 1` shifts into index `i` and is skipped in that emit cycle (left untouched in `src/core/`).
- `src/ui/settingsModal.ts` (`lines 124–136, 162–172`): constructor hides `restartBtn`/`quitBtn` when `onRestart`/`onQuitToMenu` callbacks are omitted, but `setOpen(true, settings, true)` calls `classList.toggle('hidden', !inGame)` which un-hides them even without callbacks (`GameOverlays` always passes both in-app; left untouched in `src/ui/**`).
