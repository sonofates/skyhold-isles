Each transparent source plate has five rows of six painted poses. Run the chapter packer from the repository root to rebuild the bestiary views and motion strips.

```sh
for id in duskhound veilcaster eclipse_sovereign eclipse_shade; do
  /usr/bin/python3 -B tools/sprites/chapter_enemies.py "$id" "design/art-2d/chapter5/$id.webp" public/art2d
done
```

The packer uses one scale per character and a shared foot anchor for all five clips. The three walks face right before mirroring. All four attacks make contact in frame four.
