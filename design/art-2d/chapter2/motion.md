# Chapter two enemy motion plates

The built-in image generator painted each character as a single sheet. The source plates here retain the drawn alpha edges. The packing script follows the connected silhouette of each pose, so wings can cross the nominal column boundary. All five clips share one scale and one ground anchor per animal. Each attack makes contact on frame four.

To rebuild a character from the repository root, substitute its art ID for `bellrunner` in both places.

```sh
/usr/bin/python3 -B tools/sprites/chapter_enemies.py bellrunner design/art-2d/chapter2/bellrunner.webp public/art2d
```

The output is the front and rear bestiary art in `public/art2d` and five described WebP strips in `public/art2d/anim`. The walk loops face right before renderer mirroring.
