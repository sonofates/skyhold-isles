Each transparent source plate contains five rows of six hand-painted poses. To rebuild the bestiary views and the five strips, run from the repository root:

```sh
for id in rimebeetle sledguard glacier_warden; do
  /usr/bin/python3 -B tools/sprites/chapter_enemies.py "$id" "design/art-2d/chapter4/$id.webp" public/art2d
done
```

The packer uses one scale per character and registers all five rows to the same ground anchor. Walks face right before mirroring. All three attacks make contact in frame four.
